Maildesk 物流读取助手（Chrome）

安装一次：
1. 在 Chrome 地址栏输入 chrome://extensions 并回车。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的 chrome-extension 文件夹。
4. 刷新 https://chat.thinkpro.top/maildesk/。

使用：
1. 打开客户的订单物流信息，等待 17TRACK 显示查询结果。
2. 扩展会自动读取已加载的物流窗口，无需点击；原按钮用于手动重试。
3. 等待“AI 读取”结果显示。读取时间和原文依据会保存到当前服务器。

扩展会自动读取当前客服页已加载的 extcall.17track.net 页面，不自动读取其他标签页，不保存密码，不绕过验证码。网页可见的运单信息会发送给你在客服系统中配置的 AI 服务进行识别。遇到验证码需先手动完成，再点击读取。

识别结果不是官方 API 实时回传。24 小时内的有效结果复用，过期后自动重新读取；失败最多自动尝试3次，可手动重试。没有可靠结果时保留状态未知。多包裹订单串行读取。关闭页面后不会查询，未打开的订单不会自动查询。物流异常邮件在取得可靠状态后自动更新细分类，人工分类保留。

更新旧扩展：在 chrome://extensions 点击扩展的重新加载按钮，然后刷新客服页面。

1.2.0：直接读取 Copy Details 按钮的完整原文，不读系统剪贴板。保存后用于话术 {tracking_info}；即使 AI 状态识别失败，详情仍可使用。旧版本用户需在扩展管理页重新加载扩展并刷新客服页面。
