# 待同步马帮

所有共享改址队列中 status=succeeded 的历史记录和新增记录均导入本地 SQLite 的 mabang_address_changes，顾客自助和客服等来源都纳入。每分钟串行回查全部成功记录，避免遗漏较早请求在较晚时间完成；使用只读事务、5 秒语句超时、每页 500 条。成功取得全部页面后才在本地事务中保存。

按店铺和订单合并显示，以完成时间和请求 ID 确定最新地址。人工确认记录独立保存在 mabang_address_confirmations，包含对应请求、处理人和时间，不改原改址记录、不自动写马帮。确认前再次回查，发现更新的地址会拒绝旧确认。之后再次成功改址自动回到待处理。

工作台导航“待同步马帮”显示数量，提供搜索、待处理/已处理筛选、原地址、最新地址、复制和历史；订单详情显示待同步提醒。列表、数量、历史及确认均沿用店铺邮箱权限。原始顾客邮箱不复制到本地待办。

历史上是否已人工处理无法自动判断，无明确确认记录的先待核对。上线前只读核实 9 条成功改址、9 个订单（顾客 6、其他入口 3）；不导入失败或冲突。

验证：38 项队列、自助入口、权限和网关回归测试通过；浏览器模拟接口验证导航、列表、历史、人工确认及已处理筛选。新查询服务器串行只读 3 次耗时 148.59/148.59/148.80 ms，数据库 EXPLAIN 执行时间 0.59 ms，无原订单列表 SQL 修改。未向顾客发送邮件，未调用店匠写入接口。

## 马帮模板批量导出

待办支持单选、多选和全选当前筛选结果；复制选中平台订单号时每行一个。导出前重新读取成功改址记录，所选记录被最新地址替换时停止导出，要求重新核对。

导出遵循用户提供的《订单表格更新模板.xlsx》，保留 26 列表头和省份参考列表。*编号使用平台订单号，填入最新成功地址中的姓名、电话、国家、邮编、邮寄地址、备用地址、省州、城市、区域和公司。未提供的字段留空，不猜测客户 ID、邮箱或订单备注。订单号、电话和邮编按文本写入。缺失平台订单号、重复平台订单号或缺少地址时阻止导出。

工作簿仅在浏览器内存生成，通过 Blob 下载到浏览器配置的下载位置，不上传或保存生成文件到服务器。浏览器若设置了每次询问保存位置，仍遵循该设置。下载不会自动确认同步；在马帮导入成功后，由用户手动点击“已同步马帮”。未执行真实马帮导入。

批量确认：勾选后点击“选中订单标记已同步”，统一确认仅处理选中项中的待同步订单。后台一次回查成功改址记录，逐单验证店铺权限和最新地址；任一校验失败则整批不写入。成功时逐单保存操作人和确认审计，重复提交不会重复记账。此操作不调用马帮修改接口。
