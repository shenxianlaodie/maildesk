# 待同步马帮

所有共享改址队列中 status=succeeded 的历史记录和新增记录均导入本地 SQLite 的 mabang_address_changes，顾客自助和客服等来源都纳入。每分钟串行回查全部成功记录，避免遗漏较早请求在较晚时间完成；使用只读事务、5 秒语句超时、每页 500 条。成功取得全部页面后才在本地事务中保存。

按店铺和订单合并显示，以完成时间和请求 ID 确定最新地址。人工确认记录独立保存在 mabang_address_confirmations，包含对应请求、处理人和时间，不改原改址记录、不自动写马帮。确认前再次回查，发现更新的地址会拒绝旧确认。之后再次成功改址自动回到待处理。

工作台导航“待同步马帮”显示数量，提供搜索、待处理/已处理筛选、原地址、最新地址、复制和历史；订单详情显示待同步提醒。列表、数量、历史及确认均沿用店铺邮箱权限。原始顾客邮箱不复制到本地待办。

历史上是否已人工处理无法自动判断，无明确确认记录的先待核对。上线前只读核实 9 条成功改址、9 个订单（顾客 6、其他入口 3）；不导入失败或冲突。
