# 邮箱已读状态同步

客服系统打开会话或提交已读操作时，入站邮件进入持久化 IMAP 已读队列。收信同步本身仍以只读方式进行，不会把所有新导入邮件设为已读。

- 使用每封邮件保存的邮箱、文件夹、UIDVALIDITY 和 UID，根据最后一次操作添加或移除 `\Seen`，不修改其他标记、不移动或删除邮件。
- 后台立即尝试，网络或授权错误自动退避重试，服务重启后继续处理。
- 远端标记写入后再次读取确认。UIDVALIDITY 变化或邮件不存在时保留失败记录，避免操作错误邮件。
- 状态保存在 `imap_read_jobs`，`status` 为 pending、retry、done 或 failed；错误信息不保存邮箱密码。
- 同步本系统发起的已读和未读操作。连续切换时使用版本号保护，以最后一次操作为准；不会主动导入 ZOHO 的已读状态。
- 打开此前已在本系统读过的会话，也会补发已读操作；不会批量改写未打开的历史会话。
